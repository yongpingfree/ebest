# 活动页表单接口

调用表单接口前用户需先登录，目前新增、更新接口需要用户为会员。请求 `Content-Type` 须为 `application/json`。

## 获取用户某活动填写的表单信息

### Endpoint

`GET /event_form_records`

### Request params

- `event_slug`: 活动路径，跟活动详情页面 `/event_pages/:slug` 中的 `slug` 一致，例如：`collect_dragon_balls`、`collect_slogans`

### Response body

- `id`: ID, primary key
- `data`: 用户填写的数据，目前只支持 JSON object，不支持 JSON array
- `created_at`: 创建时间
- `updated_at`: 更新时间

返回示例：

```
[
  {
    "id": 4,
    "data": {
      "1": "content 1",
      "2": "content 2"
    },
    "created_at": "2020-09-17T20:21:27.964+10:00",
    "updated_at": "2020-09-18T12:34:44.901+10:00"
  }
]
```

## 新增某活动填写的表单信息

### Endpoint

`POST /event_form_records`

### Request body

- `event_slug`: 活动路径，跟活动详情页面 `/event_pages/:slug` 中的 `slug` 一致，例如：`collect_dragon_balls`、`collect_slogans`
- `data`: 用户填写的表单信息

### Response body

- `id`: ID, primary key
- `data`: 用户填写的数据，目前只支持 JSON object，不支持 JSON array
- `created_at`: 创建时间
- `updated_at`: 更新时间

返回示例：

```
{
  "id": 4,
  "data": {
    "1": "content 1",
    "2": "content 2"
  },
  "created_at": "2020-09-17T20:21:27.964+10:00",
  "updated_at": "2020-09-18T12:34:44.901+10:00"
}
```

## 更新用户某活动填写的表单信息
### Endpoint

`PUT /event_form_records/:id`

### Route param

- `id`: 需更新表单数据的 ID

### Request body

- `data`: 用户填写的表单信息

### Response body

- `id`: ID, primary key
- `data`: 用户填写的数据，目前只支持 JSON object，不支持 JSON array
- `created_at`: 创建时间
- `updated_at`: 更新时间

返回示例：

```
{
  "id": 4,
  "data": {
    "1": "content 1",
    "2": "content 2"
  },
  "created_at": "2020-09-17T20:21:27.964+10:00",
  "updated_at": "2020-09-18T12:34:44.901+10:00"
}
```

## 错误信息

如果调用接口有错误，会返回 4xx 范围的 HTTP 状态码，并且 reponse body 会有一个 `error_message` 字段，表明错误信息。例如新增活动表单数据时没传入 `event_slug` 参数：

```
{
  error_message: "`event_slug` 参数缺失"
}
```

目前已有的错误信息：

- 400: 请求参数有误
- 401: 用户未授权
- 403: 非会员用户暂不可提交
